# Ian Derbikov — Personal Website

Single-page portfolio built with React + Vite and deployed through GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages

The workflow in `.github/workflows/deploy.yml` builds and deploys on every push to `main`.
In the repository settings, choose **Pages → Source → GitHub Actions** once.
